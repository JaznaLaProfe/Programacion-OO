# Programación Orientada a Objetos (POO)

Repositorio oficial del curso de **Programación Orientada a Objetos** para la carrera de Ingeniería Civil en Informática de la UBB, diseñado para apoyar el aprendizaje teórico y práctico de los estudiantes mediante material de clase, ejemplos de código, guías de laboratorio.

## 🎯 Objetivos del Curso

Al finalizar las unidades del curso, los y las estudiantes serán capaces de:

- Comprender y aplicar los pilares de la POO: **abstracción**, **encapsulamiento**, **herencia** y **polimorfismo**.
- Modelar problemas del mundo real mediante clases, objetos, relaciones entre entidades y diagramas (por ejemplo, UML).
- Escribir código modular, legible, mantenible y reutilizable aplicando buenas prácticas de diseño.
- Crear representaciones gráficas de lo que sucede en memoria cuando se crean objetos.
- Resolver ejercicios prácticos utilizando el entorno y usando como lenguaje de programación Java.
